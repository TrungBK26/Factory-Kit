# 🏭 FACTORY KIT - DREAM FACTORY (Game Sprint 2026)

> **Dự án dự thi Cuộc Thi Game Sprint 2026**  
> **Thể loại:** 3D Stylized Low-Poly / Factory Idle Tycoon Simulation  
> **Nền tảng:** PC Windows (Unity 6 - Universal Render Pipeline)  
> **Tác giả / Nhóm phát triển:** Kuro  

---

## 🌟 Giới Thiệu Dự Án

**Factory Kit - Dream Factory** là tựa game mô phỏng quản lý và vận hành chuỗi nhà máy sản xuất tự động theo phong cách nghệ thuật **Stylized Low-Poly Diorama** kết hợp giao diện **Pixel Retro Theme Wood** cổ điển.

Người chơi hóa thân thành người thừa kế tiếp quản khu tổ hợp công xưởng sản xuất, từng bước:
1. Thu hoạch và chế biến các loại tài nguyên từ cơ bản đến quý hiếm: Gỗ 🌲, Đá ⛏️, Đồng 🥉, Sắt 🔩, Bạc 🥈, Vàng 🥇.
2. Vận chuyển hàng hóa vào kho thành phẩm hoặc chuyển trực tiếp đến **Khu Vực Bán Hàng (Sell Area)** để kiếm tiền.
3. Sử dụng hệ thống **Tablet Quản Lý Nhà Máy từ xa (Tab)** để:
   * Mở khóa các dây chuyền máy móc mới.
   * Nâng cấp **Tier máy (1 -> 3)** tăng năng suất và thay đổi hình dạng model 3D.
   * Tăng tốc độ sản xuất và mở rộng sức chứa kho bãi.
   * **Thuê công nhân NPC tự động** vận chuyển hàng hóa thay cho người chơi.
4. Rút tiền lãi từ **Két Sắt (Vault)** để tái đầu tư và hướng tới danh hiệu **Nhà Tư Bản Công Xưởng Số 1!**

## 🎮 Phím Điều Khiển (Controls)

| Phím | Chức Năng |
| :--- | :--- |
| **`W`, `A`, `S`, `D`** / **Phím Mũi Tên** | Di chuyển nhân vật trong công xưởng |
| **`Phím F`** (hoặc giữ F) | Nhặt hàng trên băng chuyền / Bán hàng / Rút tiền từ Két sắt |
| **`Phím Tab`** / **`M`** | Mở / Đóng **Tablet Quản Lý & Nâng Cấp Nhà Máy** từ xa |
| **`Phím Esc`** | Mở / Đóng menu **Cài Đặt (Âm thanh, Lưu/Xóa Save, Hướng dẫn)** |
| **`Phím H`** | Mở bảng **Hướng Dẫn Chi Tiết** |

## 🛠️ Công Nghệ & Kỹ Thuật Nổi Bật

* **Engine:** Unity 6 (6000.4.11f1) - Universal Render Pipeline (URP).
* **Đồ họa & Môi trường:** 
  * Stylized Diorama Environment với SSAO (Screen Space Ambient Occlusion).
  * Hệ thống đường sá Low-Poly Spline tự động tạo bo cua góc nghiêng mượt mà.
  * Thảm thực vật hoa dại rực rỡ với thuật toán tự động né đường thông minh.
* **Hệ thống gameplay:**
  * Kiến trúc Decoupled Event-Driven (`GameEvents`).
  * Hệ thống kinh tế đa tầng: Ví tiền (`Wallet`) và Két sắt an toàn (`Vault`).
  * Hệ thống NPC tự động tìm đường vận chuyển hàng tuần hoàn.
  * Tự động bảo toàn và quy đổi hàng tồn kho khi thoát game.
* **Giao diện người dùng (UI):**
  * Pixel Retro Theme Wood 9-slice bo góc hoàn hảo.
  * Bảng điều khiển nâng cấp máy tối ưu thị giác, màu sắc tương phản cao.

## 📦 Hướng Dẫn Chạy Game (Bản Build PC)

1. Tải bản build PC từ thư mục `Builds/PC/` hoặc link đính kèm nộp bài.
2. Giải nén (nếu là file zip) và chạy trực tiếp file `FactoryKit.exe`.
3. Trải nghiệm gameplay mượt mà trên Windows 10/11 (64-bit).
